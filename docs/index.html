D-MORPH: decentralised self-organising multi-robot task allocation via neuroplasticity-inspired adaptive topology

Xuezhi Niu and Didem Gürdür Broo · code on GitHub · all numbers: results.md

D-MORPH is a training-free, fully decentralised coordination mechanism for heterogeneous multi-robot teams, inspired by neuroplasticity. Each robot learns whom to work with on its own, online, while the team is working: it keeps its own partner preferences and links and rewires them with biologically grounded plasticity rules, using only what it observes itself. It needs no central coordinator, no shared state, no message exchange, no task or cost model, no bidding and no offline training. In the paper it is evaluated on the TA-RWARE robotic warehouse with 8 to 24 robots.

Key idea

Multi-robot coordination usually either fixes who works with whom by a hand-designed rule (the nearest robot, robots within a radius), negotiates it through bids over a task cost model, or learns communication end-to-end with offline multi-agent reinforcement learning. MORPH showed that a coordination graph can instead self-organise online under plasticity rules, but it keeps the graph as one shared matrix, i.e. a central coordinator. D-MORPH removes the coordinator: every robot owns its row of the graph and updates it from its own target, the robots co-assigned with it, the requests it sends and receives, and its own reward.

Method

RuleBiological basisWhat each robot does with its own preferences and links
R1 synapticHebbian plasticity, reward-modulated (dopamine-gated) potentiationDecay, plus strengthening in proportion to the share of recent targets shared with the partner; completion credit when a jointly served mission is delivered.
R2 homeostaticSynaptic scalingAdjusts its readiness to form links so that its number of links stays near a target.
R3 structuralSynaptogenesis and pruningPrunes weak links after a 20-step grace period; forms a link to its best candidate (recent co-assignment and the robot it was proposed).
R4 metaplasticBCM sliding threshold, neuromodulationOver-potentiated links decay faster; explores new links when its own performance drops and consolidates when it is high.

Ablations

Package location shift

New requests come only from the upper (U) or the lower (L) half of the shelves, alternating every 400 steps over six phases (2400 steps), at Medium and Large. The delivery stations are on the lower edge.

Reproduce

pip install -r requirements.txt
python -m experiments.run all --jobs 16   # results/*.json, one file per experiment
python -m experiments.analysis            # docs/figures, docs/tables, docs/results.md
python scripts/make_videos.py             # docs/videos

Every episode is deterministic given its seed. To run D-MORPH in another benchmark or simulator, see Using D-MORPH in your own benchmark in the README.
